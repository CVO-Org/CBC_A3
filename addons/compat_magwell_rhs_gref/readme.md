# Magwell - RHS GREF

Adds the Type 69 airburst RPG round to `CBA_RPG7`, so every RPG-7 pattern launcher can fire it.

Based on [Weapons-Balance-RHS](https://github.com/johnb432/Weapons-Balance-RHS) by johnb432, MIT License, Copyright (c) 2021 johnb432. Magazine lists only, no balance changes.

Not verified against the mod's configs and not tested in game.
