# Joint Rails - Project Infinite

Adds the Project Infinite bipods to `UnderBarrelSlot_rail`, its scopes and TruGlo sights to `CowsSlot_Rail` / `asdg_OpticRail1913`, its .338 muzzle devices to `asdg_MuzzleSlot_338` and its 7.62 suppressors to the 7.62 muzzle slots.

Based on [Weapons-Balance-PI](https://github.com/johnb432/Weapons-Balance-PI) by johnb432, MIT License, Copyright (c) 2021 johnb432. Attachment lists only, no balance changes.

Not verified against the mod's configs and not tested in game.
