# Fix - RHS AFRF

- AKM and SVD have fixed stocks, but inherit the AK-74M stock folding (`rhs_fold`). Folding is removed. RHS already does this for the AK-74.

Left out from the source: the NPZ links on the folded AKS-74N, since a folded AKS-74N has no NPZ rail slot and RHS never reads them.
