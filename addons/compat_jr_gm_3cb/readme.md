# Joint Rails - Global Mobilization on 3CB

Adds the GM HK claw-mount optics and lights to the 3CB Factions G3 rail and the ATEC 7.62 suppressors to the 3CB G3 / M14 muzzle slots.

Based on [Weapons-Balance-GM](https://github.com/johnb432/Weapons-Balance-GM) by johnb432, MIT License, Copyright (c) 2021 johnb432. Attachment lists only, no balance changes.

Not verified against the mod's configs and not tested in game.
