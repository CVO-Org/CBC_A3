# Names - HLC ACR

Sets the in-game display names of the HLC ACR weapons (30) to the clearer names used by Weapons Balance - NIArms, e.g. "Remington ACR-E (Compact/'Cliffhanger')".

Based on [Weapons-Balance-NIArms](https://github.com/johnb432/Weapons-Balance-NIArms) by johnb432, MIT License, Copyright (c) 2021 johnb432. Display names only, no balance changes.
