# Fix - GEIST

GEIST weapons are built on IFA3 weapons and inherit their magazine wells, so e.g. the Carcano takes Mosin clips and the FN GP35 takes M1911 magazines. Each now uses its own well: LS/26, wz. 1928, MAS-36, FN GP35, PA 1935A, Lahti L-35, Modèle 1892, Enfield No.2; the Carcano M91 / M38, Revolver 1889 and Beretta M1935 have no shared well.

Based on [Weapons-Balance-GEIST](https://github.com/johnb432/Weapons-Balance-GEIST) by johnb432, MIT License, Copyright (c) 2021 johnb432. Config fixes only, no balance changes.

Not verified against the mod's configs and not tested in game.
