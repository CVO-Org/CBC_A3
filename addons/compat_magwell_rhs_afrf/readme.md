# Magwell - RHS AFRF

Adds RHS AFRF magazines to the shared CBA / BI wells: GP-25 / GP-30 grenades (`CBA_40mm_GP`, 15), PKM / PKP belts (`CBA_762x54R_LINKS`, 5), SVD magazines (`SVD_762x54R`, 2), RPG-7 rounds (`CBA_RPG7`, 7) and the 9K38 Igla missile (`CBA_STRELA`, 1). The 9K38 launcher accepts `CBA_STRELA`.

Left out from the source: the 5.56 AK magazines and soft pouches that Weapons Balance - RHS adds itself, the VOG-25 HEDP (a Weapons Balance class), and the Type 94 pistol in the Type 14 well (different magazine).

Based on [Weapons-Balance-RHS](https://github.com/johnb432/Weapons-Balance-RHS) by johnb432, MIT License, Copyright (c) 2021 johnb432. Magazine lists only, no balance changes.

Not verified against the mod's configs and not tested in game.
