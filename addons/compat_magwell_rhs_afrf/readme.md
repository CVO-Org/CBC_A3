# Magwell - RHS AFRF

Adds RHS AFRF magazines to the shared CBA / BI wells: GP-25 / GP-30 grenades (`CBA_40mm_GP`, 15), PKM / PKP belts (`CBA_762x54R_LINKS`, 5) and RPG-7 rounds (`CBA_RPG7`, 7).

Left out from the source: the 5.56 AK magazines and soft pouches that Weapons Balance - RHS adds itself, the VOG-25 HEDP (a Weapons Balance class), the Type 94 pistol in the Type 14 well (different magazine), the SVD magazines in `SVD_762x54R` (no RHS weapon uses that well; RHS already fills `CBA_762x54R_SVD`) and the 9K38 Igla missile in `CBA_STRELA` (no mod defines that well, so it only let the 9K32 Strela fire Igla missiles).

Based on [Weapons-Balance-RHS](https://github.com/johnb432/Weapons-Balance-RHS) by johnb432, MIT License, Copyright (c) 2021 johnb432. Magazine lists only, no balance changes.

Class names checked against the RHS AFRF 0.5.6 configs.
