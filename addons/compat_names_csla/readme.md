# Names - CSLA

Official Czechoslovak designations ("Sa vz. 58 P", "UK vz. 59 L", "vz. 82", ...) and the US85 FAL / MP5 models ("FN FAL 50.00", "HK MP5SD6"). Left out from the source: "Colt RO727 Commando" for the M16A2 carbine (the 727 is a carbine, not the Commando).

Based on [Weapons-Balance-CSLA](https://github.com/johnb432/Weapons-Balance-CSLA) by johnb432, MIT License, Copyright (c) 2021 johnb432. Display names only, no balance changes.

Not verified against the mod's configs and not tested in game.
