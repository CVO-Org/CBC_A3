# Frag - JCA Infantry Arsenal

Initially meant as an addon to add ACE frag compatibility for [JCA - Infantry Arsenal](https://steamcommunity.com/sharedfiles/filedetails/?id=3333302397) to disable fragmentation from the flare grenades, this mod covers all grenades inheriting from `JCA_GrenadeAmmo_HandFlare_Base`. Mods adding additional flares built on top of [JCA - Infantry Arsenal](https://steamcommunity.com/sharedfiles/filedetails/?id=3333302397) also have disabled fragmentation.

This addon gets loaded along with [JCA - Infantry Arsenal](https://steamcommunity.com/sharedfiles/filedetails/?id=3333302397). Both the `compat_frag_jca_hf` and this addon contain the same config changes, therefore there's no harm in both of the mentioned mods and/or addons being loaded.
