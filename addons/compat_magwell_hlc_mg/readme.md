# Magwell - HLC MG

Adds the HLC M60E4, PKM and MG42 belts and boxes to the matching shared and CBA belt wells. Wells (magazines added): `M240_762x51` (10), `PK_762x54R` (8), `CBA_762x54R_LINKS` (8), `CBA_792x57_LINKS` (4).

Based on [Weapons-Balance-NIArms](https://github.com/johnb432/Weapons-Balance-NIArms) by johnb432, MIT License, Copyright (c) 2021 johnb432. Magazine lists only, no balance changes.
