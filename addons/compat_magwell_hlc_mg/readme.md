# Magwell - HLC MG

Adds the HLC M60E4 belts to the shared `M240_762x51` well (10 magazines).

The PKM and MG34 belts from the source list are left out: NIArms All In One does not define them. HLC already adds its MG42 belts to `CBA_792x57_LINKS` itself.

Based on [Weapons-Balance-NIArms](https://github.com/johnb432/Weapons-Balance-NIArms) by johnb432, MIT License, Copyright (c) 2021 johnb432. Magazine lists only, no balance changes.
