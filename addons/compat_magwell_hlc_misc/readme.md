# Magwell - HLC Misc

Adds HLC magazines of single weapons to their CBA wells: M1903 Springfield, C96, MP5, SG550 and STGW57. Wells (magazines added): `CBA_3006_Spring` (2), `CBA_763x25_C96` (1), `CBA_9x19_MP5` (1), `CBA_556x45_SG550` (1), `CBA_762x51_SIGAMT` (1).

The Bren .303, Lee-Enfield, K98, P90, Sten and TAC-50 magazines from the source list are left out: NIArms All In One does not define them.

Based on [Weapons-Balance-NIArms](https://github.com/johnb432/Weapons-Balance-NIArms) by johnb432, MIT License, Copyright (c) 2021 johnb432. Magazine lists only, no balance changes.
