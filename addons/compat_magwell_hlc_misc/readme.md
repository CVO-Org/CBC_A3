# Magwell - HLC Misc

Adds HLC magazines of single weapons to their CBA wells: Bren, Lee-Enfield, K98, M1903 Springfield, C96, P90, MP5, Sten, TAC-50, SG550 and STGW57. Wells (magazines added): `CBA_303B_BREN` (4), `CBA_303B_LeeEn` (3), `CBA_792x57_K98` (3), `CBA_3006_Spring` (2), `CBA_763x25_C96` (1), `CBA_57x28_P90` (2), `CBA_9x19_MP5` (1), `CBA_9x19_STEN` (1), `CBA_50BMG_M107` (4), `CBA_556x45_SG550` (1), `CBA_762x51_SIGAMT` (1).

Based on [Weapons-Balance-NIArms](https://github.com/johnb432/Weapons-Balance-NIArms) by johnb432, MIT License, Copyright (c) 2021 johnb432. Magazine lists only, no balance changes.
