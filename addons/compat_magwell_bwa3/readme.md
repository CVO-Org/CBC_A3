# Magwell - BWA3

Adds the BWA3 G36 magazines to the CBA `CBA_556x45_G36` magazine well and makes the BWA3 G36 family use it, so BWA3 and HLC G36 rifles share magazines. G36 rifles never accept regular STANAG magazines.

Makes the G38 (an HK416) accept the shared `Stanag_556x45_Big` / CBA STANAG wells.

Adds the BWA3 G28 7.62x51 magazines to the shared `Stanag_762x51` / `Stanag_762x51_big` wells and makes the G28 family (G27, G28 Patrol) accept the shared 7.62x51 wells.

Based on Wolf Magazine Group Compat by Dedmen.
