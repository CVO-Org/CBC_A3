# Joint Rails - CSLA

Adds the CSLA NSPU night sight and ZD 4x8 scope to the Warsaw Pact side rails `asdg_OpticSideRail_AK` / `asdg_OpticSideRail_AKSVD`. The PGO-7 RPG-7 sight from the source is left out.

Based on [Weapons-Balance-CSLA](https://github.com/johnb432/Weapons-Balance-CSLA) by johnb432, MIT License, Copyright (c) 2021 johnb432. Attachment lists only, no balance changes.

Not verified against the mod's configs and not tested in game.
