# Joint Rails - RHS USAF on HLC

Adds RHS foregrips (17) and Harris bipods to the NIArms (HLC) underbarrel slot `nia_rifle_grips_slot`. Grips from RHS AFRF are listed too and only show up when it is loaded.

The source's own `WB_rifle_grips_slot` and its slot rename are left out, as is `nia_rifle_bipodsgrips_slot`: NIArms only declares it and no weapon uses it.

Based on [Weapons-Balance-RHS](https://github.com/johnb432/Weapons-Balance-RHS) by johnb432, MIT License, Copyright (c) 2021 johnb432. Attachment lists only, no balance changes.

Checked against the NIArms and RHS configs, not tested in game.
