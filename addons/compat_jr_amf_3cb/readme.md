# Joint Rails - AMF on 3CB

Adds the AMF Rotex III / V suppressors to the 3CB Factions HK33 muzzle slot (slot parent as in `compat_jr_hlc`).

Based on [Weapons-Balance-AMF](https://github.com/johnb432/Weapons-Balance-AMF) by johnb432, MIT License, Copyright (c) 2022 johnb432. Attachment lists only, no balance changes.

Not verified against the mod's configs and not tested in game.
