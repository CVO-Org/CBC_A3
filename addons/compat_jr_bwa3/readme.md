# Joint Rails - BWA3

Adds the B&T Rotex II to the MP7 muzzle slot `asdg_MuzzleSlot_46`, and the BWMod scopes with clip-on night sight (15, PMII / M5Xi / Hensoldt NSV) to the long rail `asdg_OpticRail1913_long`.

Based on [Weapons-Balance-BW](https://github.com/johnb432/Weapons-Balance-BW) by johnb432, MIT License, Copyright (c) 2021 johnb432. Attachment lists only, no balance changes.

Not verified against the mod's configs and not tested in game.
