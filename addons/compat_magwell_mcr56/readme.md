# Magwell - MCR56

Makes every 5.56x45 variant of RZ - MCR56 accept the CBA `CBA_556x45_MINIMI` belt well, so RHS, CUP and vanilla 200-round boxes and soft pouches fit.

Adds the MCR56 100-round pouches (all colours) to `CBA_556x45_MINIMI`, so any MCR56 colour takes any pouch colour. As a side effect, other M249-type weapons (RHS, CUP, vanilla LIM-85) also accept these pouches; this is intended.

Sets the model switch so the weapon shows the right model for the loaded magazine: the listed belts (MCR56, vanilla, RHS USAF, CUP) switch to the 100-round or 200-round model, and any other magazine switches to the stick-magazine model. Belts not listed here still load and fire but show the stick-magazine model.

The CSAT 5.8x42 variants are not changed.

Based on MCR56 CBA_A3 Compat by WhiteFox.
