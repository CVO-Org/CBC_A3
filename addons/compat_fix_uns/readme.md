# Fix - Unsung

Unsung weapons that inherit another weapon's wells get their own: the launcher base (RPG-32), RPG-7, Bazooka, Sa vz. 58 P (AK), M40 (.30-06 Model 70), Uk vz. 59, shotgun tube capacities (M1897, Baikal, Ithaca 37), K-50M (PPS-43), Owen (Sten) and Sa vz. 61 (PM-63).

Based on [Weapons-Balance-Unsung](https://github.com/johnb432/Weapons-Balance-Unsung) by johnb432, MIT License, Copyright (c) 2021 johnb432. Config fixes only, no balance changes.

Not verified against the mod's configs and not tested in game.
