# Magwell - ACE

Adds ACE3 7.62x51 / 5.56x45 magazines and the HuntIR grenade to the shared `Stanag_*` / `UGL_m230` magazine wells.

ACE ammo is treated as generic, so the 7.62x51 magazines are also added to the pattern-specific CBA wells (`CBA_762x51_AR10`, `_HK417`, `_M14`, `_SCAR`, `_G3`). This favours broad availability over strict realism, so ACE ammo types work in the AR-10, HK417, M14, SCAR and G3 pattern rifles.

Based on Wolf Magazine Group Compat by Dedmen.
