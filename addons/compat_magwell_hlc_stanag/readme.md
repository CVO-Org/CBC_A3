# Magwell - HLC STANAG

Adds 34 more HLC 5.56x45 STANAG magazines (PMAG and other variants) to the vanilla `STANAG_556x45` well, and the HLC 50-round magazines to `CBA_556x45_STANAG_L`. The HK33/HK53 magazines are covered by Magwell - HLC G3.

Based on [Weapons-Balance-NIArms](https://github.com/johnb432/Weapons-Balance-NIArms) by johnb432, MIT License, Copyright (c) 2021 johnb432. Magazine lists only, no balance changes.
