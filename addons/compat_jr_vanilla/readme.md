# Joint Rails - Vanilla

Puts the Contact DLC MSBS on CBA Joint Rails' `asdg_OpticRail1913` (optic) and `asdg_FrontSideRail` (pointer) slots, which CBA Joint Rails does not cover. The real MSBS Grot has a full-length top Picatinny rail and accepts Picatinny sections for lights and lasers on its handguard.

Slots only, no changes to the weapon itself. Based on the GSRI gear patch (MIT).
