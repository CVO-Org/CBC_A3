# Magwell - JCA Infantry Arsenal

Same magazine well compatibility as the standalone `compat_magwell_jca_*` addons, for the combined JCA - Infantry Arsenal mod (which uses different CfgPatches names).

Covers the M4A1 / M4A4 / SR10 / SR25, M16A4, HK433, HK437, SCAR-H / SCAR-L, P226, M9A1, G17, MP5, UMP, MP7, M107 and M115A3. The magazine lists come from the `magazines.hpp` of each standalone addon.

The standalone addons skip themselves via `skipWhenAnyAddonPresent[]` when Infantry Arsenal is loaded, so only one variant is ever active.
