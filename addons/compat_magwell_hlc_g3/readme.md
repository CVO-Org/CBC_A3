# Magwell - HLC G3

Adds HLC G3 7.62x51 magazines to the CBA `CBA_762x51_G3` well (and the SIG AMT and M14 magazines to their own CBA wells), and HLC HK33/HK53 5.56x45 magazines to the shared `Stanag_556x45*` wells. Makes those rifles accept the matching CBA wells.

Based on Wolf Magazine Group Compat by Dedmen.
