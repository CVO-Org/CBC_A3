# Names - RHS GREF

Uses the official Czech designations for the Sa vz. 58 ("Sa vz. 58 P" fixed stock, "Sa vz. 58 V" folding stock), and names its rail, colour and stock variants (14). Also uses the real names "MG 42", "StG 44" and "Kar98k", and names the M21 tracer magazine.

Based on [Weapons-Balance-RHS](https://github.com/johnb432/Weapons-Balance-RHS) by johnb432, MIT License, Copyright (c) 2021 johnb432. Display names only, no balance changes.

Not verified against the mod's configs and not tested in game.
