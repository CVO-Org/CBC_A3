# Frag - JCA Hand Flares

ACE frag compatibility for JCA hand flares, disabling fragmentation from the flare grenades. Covers all grenades inheriting from `JCA_GrenadeAmmo_HandFlare_Base`, so mods adding additional flares built on top of [JCA - Hand Flares](https://steamcommunity.com/sharedfiles/filedetails/?id=2991684121) also have disabled fragmentation.

This addon gets disabled when [JCA - Infantry Arsenal](https://steamcommunity.com/sharedfiles/filedetails/?id=3333302397) is loaded in favor of the `compat_frag_jca_ia` addon.
