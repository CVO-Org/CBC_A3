# Names - RHS SAF

Names the folded Zastava M70AB2 / M92 / M21, G36C / G36KV and Minimi Para variants, and the black and FDE SCAR-H by length, colour and stock state, e.g. "SCAR-H CQC (FDE/Folded)" (21).

The Mk 17 Mod 0 and SCAR-H (USA) names are in Names - RHS USAF, since those rifles are defined there.

Based on [Weapons-Balance-RHS](https://github.com/johnb432/Weapons-Balance-RHS) by johnb432, MIT License, Copyright (c) 2021 johnb432. Display names only, no balance changes.

Checked against the RHS SAF configs, not tested in game.
