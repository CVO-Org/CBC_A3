# Names - RHS SAF

Names the folded Zastava M70AB2 / M92 / M21, G36C / G36KV and Minimi Para variants, and the SCAR-H family by length, colour and stock state, with "Mk 17 Mod 0" for the US SOCOM rifles (34).

Requires RHS SAF (and so all four RHS mods) because not every class here can be placed in one RHS mod without the configs: an override of a class that is not loaded would add a new item instead.

Based on [Weapons-Balance-RHS](https://github.com/johnb432/Weapons-Balance-RHS) by johnb432, MIT License, Copyright (c) 2021 johnb432. Display names only, no balance changes.

Not verified against the mod's configs and not tested in game.
