# Names - 3CB Factions

Real designations for 3CB Factions weapons (63), e.g. "Lee-Enfield No.4 Mk.I (T) (Walnut)", "HK G36KV (TAC)", "FN FAL 50.62 (RIS)", "MG3-KWS", "Sterling L2A3 (Mk.4)", "M1928A1 Thompson".

Left out from the source: the fictional G36 MLI(C) names and "Colt M4 Carbine" for the M16A2-based carbine.

Not verified against the mod's configs and not tested in game.
