# Magwell - RHS USAF

Adds RHS USAF 5.56x45 and 7.62x51 magazines to the shared `Stanag_*` magazine wells and makes the M4 accept the shared 5.56x45 STANAG wells.

Makes the XM2010 accept the `M2010_300wm` / CBA `CBA_300WM_AICS` wells, so HLC AWC .300 Win Mag magazines fit.

The M14 EBR-RI uses only the CBA `CBA_762x51_M14` well, which the RHS 20-round 7.62x51 magazines are added to.

Based on Wolf Magazine Group Compat by Dedmen.
