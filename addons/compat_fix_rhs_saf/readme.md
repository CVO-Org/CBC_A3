# Fix - RHS SAF

- The M70B1 and M70B3 have fixed stocks, but inherit the M70AB2 stock-folding action. The action is removed.
- The fired M80 Zolja tube inherits the base weapon of the loaded launcher, so the arsenal turns a used tube back into a fresh one. Both now point to themselves, and the used tube is named "M80 Zolja (Used)".
