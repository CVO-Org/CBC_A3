# Joint Rails - 3CB on HLC

Adds the 3CB M14-mount AN/PVS-4 and ART scopes to the NIArms (HLC) M14 optic rail `niarms_m14_OpticRail`.

Based on [Weapons-Balance-3CBFactions](https://github.com/johnb432/Weapons-Balance-3CBFactions) by johnb432, MIT License, Copyright (c) 2021 johnb432. Attachment lists only, no balance changes.

Not verified against the mod's configs and not tested in game.
