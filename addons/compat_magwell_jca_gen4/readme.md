# Magwell - JCA Gen 4

Adds the JCA PMAG 5.56x45 magazines to the shared `Stanag_556x45_Big` / `CBA_556x45_STANAG` magazine wells and makes the M4A1 and M4A4 accept the shared 5.56x45 STANAG wells.

Adds the JCA SR PMAG / SMAG 7.62x51 magazines to the shared `Stanag_762x51` / `Stanag_762x51_big` / `CBA_762x51_SR25` / `CBA_762x51_AR10` wells and makes the SR10 and SR25 accept the shared 7.62x51 wells.
