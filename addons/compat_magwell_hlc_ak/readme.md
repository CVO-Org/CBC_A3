# Magwell - HLC AK

Adds the HLC AK / RPK 5.45x39, 7.62x39 and 5.56x45 magazines, the Saiga 12 gauge magazines and the VOG-25 / GRD grenades to the matching CBA and shared wells. Wells (magazines added): `CBA_545x39_AK` (9), `CBA_545x39_RPK` (6), `CBA_762x39_AK` (10), `CBA_762x39_RPK` (4), `CBA_556x45_AK` (8), `CBA_12g_SAIGA` (4), `VOG_40mm` (8).

Based on [Weapons-Balance-NIArms](https://github.com/johnb432/Weapons-Balance-NIArms) by johnb432, MIT License, Copyright (c) 2021 johnb432. Magazine lists only, no balance changes.
