# Magwell - HLC AK

Adds the HLC AK-74 / AK-12 standard 5.45x39 magazines, the Saiga 12 gauge magazines and the VOG-25 / GRD grenades to the matching CBA and shared wells. Wells (magazines added): `CBA_545x39_AK` (3), `CBA_12g_SAIGA` (2), `VOG_40mm` (8).

HLC already adds its own AK / RPK magazines to the CBA 5.45 and 7.62x39 wells. The dim-tracer, 5.56 AK and 12-round Saiga magazines from the source list are left out: NIArms All In One does not define them.

Based on [Weapons-Balance-NIArms](https://github.com/johnb432/Weapons-Balance-NIArms) by johnb432, MIT License, Copyright (c) 2021 johnb432. Magazine lists only, no balance changes.
