# Fix - 3CB Factions

Gives 3CB Factions weapons that inherit another weapon's magazine wells their own wells: the RPD (inherits the 7.62x54R Zafir), SKS (the 7.92 M76), Uzi (the Scorpion), PPSh-41 (the PP-2000), MP5 and MP5/10 (the vanilla Sting), AUG A2 Para (9 mm, not 5.56), Stgw 57 / SIG 510-4, M1903A1, and the Uk vz. 59N (7.62x51 NATO, so no 7.62x54R belt well).

Based on [Weapons-Balance-3CBFactions](https://github.com/johnb432/Weapons-Balance-3CBFactions) by johnb432, MIT License, Copyright (c) 2021 johnb432. Config fixes only, no balance changes.

Not verified against the mod's configs and not tested in game.
